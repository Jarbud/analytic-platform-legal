Terms of Service

Madu Kencono API adalah platform analitik pribadi untuk mengelola konten sosial media suppliermaduaslimadukencona.com. Data yang dikumpulkan terbatas pada performa video milik pemilik akun (views, likes, comments, shares) melalui TikTok Display API. Tidak ada data pengguna pihak ketiga yang dikumpulkan, dijual, atau dibagikan.

Penggunaan Data

Data video TikTok hanya disimpan di server lokal pemilik akun dan digunakan untuk keperluan analitik internal.
