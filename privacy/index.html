Privacy Policy

Madu Kencono API ("Aplikasi") hanya mengakses data video dari akun TikTok pemilik yang telah memberikan otorisasi melalui Login Kit.

Data yang Dikumpulkan

  • Informasi video: ID, judul, deskripsi, tanggal posting, jumlah views, likes, comments, shares (dari TikTok Display API)
  • Token akses OAuth: disimpan terenkripsi di server lokal

Penggunaan Data

Data digunakan semata-mata untuk analitik performa konten. Tidak ada iklan, tracking pihak ketiga, atau berbagi data dengan pihak luar.
